## Probieren Sie diese Schritte nacheinander

1. **In der Taskleiste nachsehen:** Schauen Sie auf die Leiste ganz unten. Hat das Programm dort ein Symbol mit einem kleinen Strich darunter? Klicken Sie darauf. Das Fenster kommt zurück.
2. **Alle Fenster anzeigen:** Drücken Sie gleichzeitig <kbd>Alt</kbd> + <kbd>Tab ↹</kbd>. Halten Sie <kbd>Alt</kbd> gedrückt. Sie sehen alle offenen Fenster. Tippen Sie so oft auf <kbd>Tab ↹</kbd>, bis das richtige umrandet ist. Lassen Sie dann los.
3. **Kein Symbol da?** Dann wurde das Programm geschlossen. Öffnen Sie es neu über das Windows-Symbol unten. Word zeigt Ihre letzte Datei unter **Zuletzt verwendet**.

> **Gut zu wissen:** Das passiert oft durch einen Klick auf den Strich ( – ) oben rechts im Fenster. Dann ist das Fenster nur nach unten in die Taskleiste gerutscht. Mehr dazu in [„Wie öffne, schließe und wechsle ich Fenster?“](../../pc-grundlagen/fenster/).

## Das Programm reagiert nicht mehr

1. Warten Sie eine Minute. Manchmal ist der Computer nur beschäftigt.
2. Oben im Fenster steht **(Keine Rückmeldung)**? Klicken Sie oben rechts auf das Kreuz ( ✕ ).
3. Windows fragt, ob Sie das Programm schließen möchten. Klicken Sie auf **Programm schließen**.
4. Öffnen Sie das Programm danach neu. Word bietet oft an, Ihren Text wiederherzustellen. Klicken Sie dann auf die angezeigte Datei.

## Hat nicht geklappt?

- **Der ganze Bildschirm ist eingefroren:** Halten Sie den Ein-Schalter des Computers etwa 10 Sekunden gedrückt, bis er ausgeht. Schalten Sie ihn danach wieder ein.
