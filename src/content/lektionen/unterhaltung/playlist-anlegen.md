## Eine neue Playlist anlegen

1. Tippen Sie unten auf **Bibliothek**.
2. Tippen Sie oben rechts auf das **Plus ( + )**.
3. Wählen Sie **Playlist**.
4. Geben Sie einen Namen ein, zum Beispiel **Lieder zum Kaffee**. Tippen Sie auf **Erstellen**.
5. Ihre neue Playlist ist noch leer. Sie finden sie ab jetzt in der **Bibliothek**.

## Ein Lied zur Playlist hinzufügen

1. Suchen Sie das Lied, wie in der Anleitung [„Wie finde ich ein Lied bei Spotify?“](../lieder-suchen/) beschrieben.
2. Rechts neben dem Lied sind **drei Punkte ( ⋯ )**. Tippen Sie darauf.
3. Wählen Sie **Zur Playlist hinzufügen**.
4. Tippen Sie auf den Namen Ihrer Playlist. Tippen Sie, falls nötig, unten auf **Fertig**.
5. Das Lied ist jetzt in Ihrer Playlist.

> **Gut zu wissen:** Es geht auch schneller: Tippen Sie neben dem Lied auf das **Plus im Kreis**. Dann landet das Lied in **Lieblingssongs**, Ihrer Sammlung von Lieblingsliedern. Das Plus wird zu einem grünen Haken.

## Die Playlist anhören

1. Tippen Sie unten auf **Bibliothek** und dann auf Ihre Playlist.
2. Tippen Sie auf den großen **grünen Knopf** mit dem Dreieck ( ▶ ). Die Lieder spielen nacheinander.

## Jetzt Sie!

Legen Sie eine Playlist mit dem Namen **Meine Lieblingslieder** an. Fügen Sie drei Lieder hinzu, die Sie gerne hören.

## Hat nicht geklappt?

- **Ich finde meine Playlist nicht:** Tippen Sie unten auf **Bibliothek**. Ganz oben können Sie auf **Playlists** tippen. Dann sehen Sie nur noch Ihre Listen.
- **Das Lied ist in der falschen Playlist:** Kein Problem. Wie Sie es dort wieder herausnehmen, lesen Sie in der nächsten Anleitung.
