**Rufen Sie niemals die Nummer an**, die in so einer Warnung steht. Klicken Sie nichts an und laden Sie nichts herunter. Echte Warnungen von Windows nennen nie eine Telefonnummer.

## So sieht der Trick aus

1. Das Fenster füllt den ganzen Bildschirm. Oft ist es rot oder blau mit einem Microsoft-Logo.
2. Es piept oder eine Stimme spricht. Dort steht zum Beispiel: „Ihr Computer ist gesperrt“ oder „Virus gefunden“.
3. Sie sollen sofort eine Nummer anrufen oder ein Programm herunterladen.

## So werden Sie die Warnung los

1. Bleiben Sie ruhig. Der Computer ist **nicht** kaputt und **nicht** gesperrt.
2. Drücken Sie gleichzeitig <kbd>Alt</kbd> + <kbd>F4</kbd>. Das schließt den [Browser](../../glossar/#browser) samt Warnung.
3. Geht der Browser nicht zu? Drücken Sie <kbd>Strg</kbd> + <kbd>Alt</kbd> + <kbd>Entf</kbd>. Klicken Sie auf **Task-Manager**, dann auf **Microsoft Edge** und auf **Task beenden**.
4. Hilft auch das nicht? Halten Sie den Ein-Schalter des Computers etwa 10 Sekunden gedrückt. Der Computer geht aus. Schalten Sie ihn danach wieder ein.
5. Öffnet sich die Warnung beim Starten des Browsers erneut? Klicken Sie auf **Nicht wiederherstellen**, wenn Edge das fragt.

> **Gut zu wissen:** Ihr Computer hat mit **Windows-Sicherheit** schon einen Virenschutz eingebaut. Sie brauchen kein zusätzliches Programm, auch wenn eine Werbung das behauptet.

## Jetzt Sie!

Merken Sie sich die Tasten <kbd>Alt</kbd> + <kbd>F4</kbd>. Üben Sie sie einmal mit einem harmlosen Fenster, zum Beispiel dem Browser.

## Hat nicht geklappt?

- **Ich habe die Nummer schon angerufen:** Legen Sie auf und schalten Sie den Computer aus. Lesen Sie [„Ein Anrufer will auf meinen Computer“](../falscher-support/) und [„Ich bin auf Betrug hereingefallen“](../notfall/).
