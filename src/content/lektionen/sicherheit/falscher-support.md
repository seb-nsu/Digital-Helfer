<div class="warnung">

**Microsoft ruft Sie niemals von sich aus an.** Wer anruft und sagt „Ich bin von Microsoft“, ist ein Betrüger. Legen Sie einfach auf.

</div>

## So erkennen Sie den Trick

1. **Der Anruf:** Jemand spricht oft Englisch oder gebrochenes Deutsch. Er sagt, Ihr Computer sei in Gefahr.
2. **Die Warnung im Internet:** Plötzlich füllt ein Fenster den Bildschirm. Es piept vielleicht. Dort steht: „Ihr Computer ist gesperrt. Rufen Sie sofort diese Nummer an.“
3. **Das Ziel:** Sie sollen ein Programm installieren, zum Beispiel AnyDesk oder TeamViewer. Damit steuern die Betrüger Ihren Computer.

## So reagieren Sie richtig

1. **Am Telefon:** Legen Sie auf. Geben Sie keine Daten heraus.
2. **Bei einer Warnung im Internet:** Rufen Sie die Nummer **nicht** an. Das Fenster ist nur eine Internetseite und harmlos, solange Sie nichts tun.
3. **Fenster schließen:** Drücken Sie gleichzeitig <kbd>Alt</kbd> + <kbd>F4</kbd>. Das schließt den [Browser](../../glossar/#browser).
4. **Geht das nicht?** Halten Sie den Ein-Schalter des Computers etwa 10 Sekunden gedrückt. Der Computer geht aus. Schalten Sie ihn danach wieder ein.

> **Gut zu wissen:** Auf Ihren Bildschirm schauen darf nur jemand, den Sie selbst angerufen haben. Zum Beispiel über die Hilfe-Seite dieses Digital-Helfers.

## Jetzt Sie!

Üben Sie das Schließen: Öffnen Sie den Browser. Drücken Sie <kbd>Alt</kbd> + <kbd>F4</kbd>. Der Browser schließt sich.

## Hat nicht geklappt?

- **Der Betrüger war schon auf meinem Computer:** Schalten Sie den Computer aus. Lesen Sie die Anleitung [„Ich bin auf Betrug hereingefallen. Was jetzt?“](../notfall/) und holen Sie Hilfe.
