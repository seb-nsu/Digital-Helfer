## Die App laden

1. Tippen Sie auf dem iPhone auf das blaue Symbol **App Store**.
2. Tippen Sie unten rechts auf **Suchen** (die Lupe). Tippen Sie oben **DB Navigator** ein.
3. Achten Sie darauf, dass darunter **Deutsche Bahn** als Hersteller steht.
4. Tippen Sie auf **Laden**. Bestätigen Sie mit Face ID oder Ihrem Apple-Passwort.
5. Öffnen Sie die App. Beim ersten Start fragt sie, ob sie Ihnen Mitteilungen schicken darf. Tippen Sie auf **Erlauben**. Dann meldet die App Verspätungen.

## Eine Verbindung suchen

1. Tippen Sie unten auf **Suche**.
2. Tippen Sie auf **Start** und tippen Sie Ihren Bahnhof ein. Wählen Sie den passenden Vorschlag aus der Liste.
3. Tippen Sie auf **Ziel** und machen Sie es genauso.
4. Tippen Sie auf das Datum und wählen Sie Tag und Uhrzeit.
5. Haben Sie eine **BahnCard**? Tippen Sie auf **Reisende** und geben Sie dort die BahnCard an. Dann sehen Sie gleich den richtigen Preis.
6. Tippen Sie auf **Suchen**. Sie sehen die Verbindungen mit Uhrzeiten und Preisen.

## Die Fahrkarte kaufen

1. Tippen Sie auf eine passende Verbindung. Sie sehen, wo Sie umsteigen müssen.
2. Tippen Sie auf **Weiter** und wählen Sie den Preis. **Sparpreise** gelten nur für diesen Zug. Der **Flexpreis** gilt für jeden Zug an diesem Tag.
3. Möchten Sie einen festen Sitzplatz? Wählen Sie **Sitzplatz reservieren**.
4. Melden Sie sich an. Beim ersten Mal legen Sie ein Konto an: Name, E-Mail-Adresse und ein [Passwort](../../sicherheit/passwoerter/). Sie können auch **ohne Anmeldung** kaufen. Mit Konto finden Sie Ihre Fahrkarten aber leichter wieder.
5. Wählen Sie die Zahlungsart. Mit PayPal geht das so, wie in [„Wie bezahle ich mit PayPal?“](../paypal/) beschrieben.
6. Prüfen Sie Datum, Uhrzeit und Preis. Tippen Sie auf **Jetzt kaufen**. Erst jetzt ist die Fahrkarte gekauft.

## Die Fahrkarte im Zug zeigen

1. Öffnen Sie im Zug die App **DB Navigator**.
2. Tippen Sie unten auf **Reisen** oder **Meine Reisen**. Dort stehen alle gekauften Fahrkarten.
3. Tippen Sie auf die Fahrt und dann auf **Ticket anzeigen**. Sie sehen einen großen [QR-Code](../../glossar/#qr-code).
4. Zeigen Sie diesen Code der Schaffnerin oder dem Schaffner. Halten Sie auch Ihren Ausweis oder Ihre BahnCard bereit.

> **Gut zu wissen:** Die Fahrkarte ist in der App gespeichert. Sie können sie auch zeigen, wenn im Zug das Internet schwach ist. Öffnen Sie die Fahrkarte aber zur Sicherheit schon einmal zu Hause, bevor Sie losfahren. Achten Sie außerdem darauf, dass Ihr iPhone geladen ist.

## Jetzt Sie!

Laden Sie die App DB Navigator. Suchen Sie eine Verbindung von Ihrem Bahnhof in eine Stadt, die Sie gern besuchen. Schauen Sie sich die Preise an. Sie müssen nichts kaufen.

## Hat nicht geklappt?

- **Die Fahrkarte ist nicht in der App:** Haben Sie ohne Anmeldung gekauft? Dann tippen Sie bei **Reisen** auf **Reise hinzufügen**. Tippen Sie den Auftragscode aus der E-Mail und Ihren Nachnamen ein.
- **Der Bildschirm ist zu dunkel zum Vorzeigen:** Ziehen Sie auf dem iPhone von oben rechts nach unten und schieben Sie die Helligkeit nach oben.
- **Lieber auf Papier:** Die Fahrkarte kommt auch per E-Mail. Drucken Sie sie aus, wie in [„Wie kaufe ich eine Fahrkarte bei der Bahn?“](../bahn-ticket/) beschrieben.
