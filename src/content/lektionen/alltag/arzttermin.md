## Den Weg zur Buchung finden

1. Schauen Sie auf die Internetseite Ihrer Praxis. Gibt es dort einen Knopf wie **Termin online buchen**? Dann klicken Sie darauf.
2. Oft öffnet sich dann die Seite **Doctolib**. Sie können auch direkt **doctolib.de** eintippen und den Namen Ihres Arztes suchen.

## Einen Termin buchen

1. Wählen Sie den Grund, zum Beispiel **Vorsorge** oder **Sprechstunde**.
2. Sie sehen freie Termine. Klicken Sie auf einen passenden Tag und eine Uhrzeit.
3. Beim ersten Mal legen Sie ein Konto an: E-Mail-Adresse, ein [Passwort](../../sicherheit/passwoerter/) und Ihre Handynummer.
4. Sie bekommen einen Code per SMS. Tippen Sie ihn ein.
5. Prüfen Sie alles und klicken Sie auf **Termin bestätigen**. Sie bekommen eine E-Mail mit dem Termin.

> **Gut zu wissen:** Doctolib erinnert Sie vor dem Termin per SMS oder E-Mail. Absagen können Sie über den Link in dieser E-Mail. Für Facharzttermine hilft auch die Terminservicestelle unter der Nummer **116 117** oder auf **116117.de**.

## Jetzt Sie!

Suchen Sie bei Doctolib nach Ihrer Hausarztpraxis. Schauen Sie nach, ob sie Termine im Internet anbietet. Sie müssen nichts buchen.

## Hat nicht geklappt?

- **Meine Praxis ist nicht dabei:** Nicht jede Praxis bietet Online-Termine an. Dann rufen Sie wie gewohnt an.
- **Die SMS mit dem Code kommt nicht:** Warten Sie eine Minute. Klicken Sie dann auf **Code erneut senden**.
