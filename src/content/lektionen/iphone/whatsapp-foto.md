## Ein Foto aus Ihrer Sammlung schicken

1. Öffnen Sie **WhatsApp** und tippen Sie auf den Chat, zum Beispiel mit Ihrem Sohn.
2. Tippen Sie unten links neben dem Schreibfeld auf das **Plus ( + )**.
3. Tippen Sie auf **Fotos**. Ihre Fotos erscheinen.
4. Tippen Sie auf das Foto, das Sie schicken möchten. Für mehrere Fotos tippen Sie nacheinander auf jedes. Es erscheint ein Haken.
5. Unten können Sie noch einen Text dazuschreiben, zum Beispiel **Schöne Grüße aus dem Garten!**
6. Tippen Sie unten rechts auf den **blauen oder grünen Pfeil**. Das Foto wird geschickt.

## Ein neues Foto aufnehmen und schicken

1. Tippen Sie im Chat unten rechts auf das **Kamera-Symbol**.
2. Halten Sie das iPhone auf das Motiv. Tippen Sie auf den großen **weißen Kreis**.
3. Gefällt Ihnen das Foto? Tippen Sie auf den **Pfeil**, um es zu schicken. Sonst tippen Sie oben links auf das **Kreuz** und versuchen es noch einmal.

> **Gut zu wissen:** Zwei graue Haken unter dem Foto heißen: Es ist angekommen. Werden die Haken **blau**, hat die Person es gesehen.

## Jetzt Sie!

Machen Sie ein Foto von etwas in Ihrer Wohnung. Schicken Sie es Sebastian per WhatsApp.

## Hat nicht geklappt?

- **WhatsApp fragt, ob es auf Ihre Fotos zugreifen darf:** Tippen Sie auf **Vollen Zugriff erlauben** oder **Zugriff auf alle Fotos**. Sonst sieht WhatsApp Ihre Fotos nicht.
- **Das falsche Foto ist verschickt:** Halten Sie den Finger lange auf das Foto im Chat. Tippen Sie auf **Löschen** und dann auf **Für alle löschen**.
