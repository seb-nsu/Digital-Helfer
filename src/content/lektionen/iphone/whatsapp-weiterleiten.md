## Eine Nachricht weiterleiten

1. Öffnen Sie den Chat mit der Nachricht oder dem Foto.
2. Legen Sie den Finger auf die Nachricht und **halten Sie ihn etwa eine Sekunde**. Ein Menü erscheint.
3. Tippen Sie auf **Weiterleiten**. Die Nachricht hat jetzt einen Haken.
4. Möchten Sie mehrere Nachrichten weiterleiten? Tippen Sie auf die Kreise links neben weiteren Nachrichten.
5. Tippen Sie unten auf den **Pfeil** (unten links oder rechts).
6. Wählen Sie die Person oder Gruppe, an die die Nachricht gehen soll. Sie können auch mehrere antippen.
7. Tippen Sie auf **Weiterleiten** oder auf den Pfeil zum Senden.

> **Gut zu wissen:** Weitergeleitete Nachrichten haben oben den Hinweis **Weitergeleitet**. So sieht der Empfänger, dass die Nachricht nicht von Ihnen selbst stammt.

<div class="warnung">

**Vorsicht bei Kettenbriefen:** Nachrichten wie „Bitte an alle weiterleiten!“ oder angebliche Warnungen sind oft falsch. Leiten Sie solche Nachrichten nicht weiter. Fragen Sie im Zweifel nach.

</div>

## Jetzt Sie!

Leiten Sie ein schönes Foto aus einem Chat an Sebastian weiter.

## Hat nicht geklappt?

- **Es erscheint kein Menü:** Halten Sie den Finger etwas länger auf der Nachricht, ohne ihn zu bewegen.
- **Ich habe an die falsche Person weitergeleitet:** Halten Sie den Finger auf die weitergeleitete Nachricht. Tippen Sie auf **Löschen** und dann auf **Für alle löschen**.
