## Die Gruppe finden

1. Öffnen Sie **WhatsApp** und tippen Sie unten auf **Chats**.
2. Eine Gruppe erkennen Sie am **Gruppennamen**, zum Beispiel **Familie**, und oft an einem gemeinsamen Bild.
3. Unter dem Namen steht, wer zuletzt geschrieben hat. Tippen Sie auf die Gruppe.
4. Im Chat steht über jeder Nachricht der **Name** der Person, die sie geschrieben hat.

## Etwas an alle schicken

1. Tippen Sie unten in das Schreibfeld und schreiben Sie Ihre Nachricht.
2. Tippen Sie auf den **Pfeil**. Jetzt sehen alle in der Gruppe Ihre Nachricht.
3. Fotos und Sprachnachrichten schicken Sie genauso wie in einem Chat mit einer Person. Lesen Sie dazu [„Wie schicke ich ein Foto mit WhatsApp?“](../whatsapp-foto/) und [„Wie schicke und höre ich eine Sprachnachricht?“](../whatsapp-sprachnachricht/).

<div class="warnung">

**Alle lesen mit:** Was Sie in die Gruppe schreiben, sehen **alle** Mitglieder. Etwas Persönliches schicken Sie lieber nur an eine Person im eigenen Chat.

</div>

## Auf eine bestimmte Nachricht antworten

In einer Gruppe wird viel geschrieben. Damit klar ist, worauf Sie antworten:

1. Legen Sie den Finger auf die Nachricht und **wischen Sie nach rechts**.
2. Die Nachricht erscheint klein über dem Schreibfeld.
3. Schreiben Sie Ihre Antwort und tippen Sie auf den **Pfeil**. Alle sehen, worauf Sie antworten.

## Mit einem Bildchen reagieren

Manchmal reicht ein kurzes Zeichen, zum Beispiel ein **Daumen hoch** oder ein **Herz**.

1. Halten Sie den Finger **lange** auf die Nachricht oder das Foto.
2. Oben erscheint eine Reihe mit kleinen Bildchen, den **Emojis**.
3. Tippen Sie auf eines, zum Beispiel das **Herz**. Es erscheint klein unter der Nachricht.

> **Gut zu wissen:** Eine neue Gruppe legen Sie selten selbst an. Lassen Sie sich von {{helfer-dativ}} in die Familiengruppe aufnehmen. Piept die Gruppe zu oft, lesen Sie [„Wie schalte ich eine Gruppe leise?“](../whatsapp-gruppe-stumm/).

## Jetzt Sie!

Öffnen Sie Ihre Familiengruppe. Antworten Sie auf die letzte Nachricht, indem Sie sie nach rechts wischen. Reagieren Sie auf ein Foto mit einem Herz.

## Hat nicht geklappt?

- **Beim Wischen passiert nichts:** Wischen Sie langsam und auf der Nachricht selbst, nicht daneben.
- **Ich habe eine Nachricht in die falsche Gruppe geschickt:** Halten Sie den Finger lange auf die Nachricht. Tippen Sie auf **Löschen** und dann auf **Für alle löschen**.
