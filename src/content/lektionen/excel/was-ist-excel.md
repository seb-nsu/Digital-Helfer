## Excel öffnen

1. Klicken Sie unten auf das Windows-Symbol. Tippen Sie **Excel** und klicken Sie auf **Excel** in der Liste.
2. Klicken Sie auf **Leere Arbeitsmappe**. Eine leere Tabelle erscheint.

## Zeilen, Spalten und Zellen

1. **Spalten** laufen von oben nach unten. Sie haben Buchstaben: **A**, **B**, **C** und so weiter. Die Buchstaben stehen ganz oben.
2. **Zeilen** laufen von links nach rechts. Sie haben Zahlen: **1**, **2**, **3** und so weiter. Die Zahlen stehen ganz links.
3. Jedes Kästchen heißt **[Zelle](../../glossar/#zelle)**. Ihr Name setzt sich aus Spalte und Zeile zusammen. Das Kästchen in Spalte B und Zeile 3 heißt **B3**. Wie beim Spiel „Schiffe versenken“.
4. Die ausgewählte Zelle hat einen grünen Rahmen. Ihren Namen sehen Sie oben links über der Tabelle.

## Etwas eintragen

1. Klicken Sie einmal auf eine Zelle, zum Beispiel **A1**.
2. Tippen Sie ein Wort oder eine Zahl ein.
3. Drücken Sie <kbd>↵ Enter</kbd>. Excel springt eine Zelle nach unten.
4. Möchten Sie lieber nach rechts springen? Drücken Sie die Taste <kbd>Tab ↹</kbd> links auf der Tastatur.

> **Gut zu wissen:** Sie möchten eine Zelle ändern? Klicken Sie darauf und tippen Sie einfach neu. Der alte Inhalt wird ersetzt. Mit <kbd>Entf</kbd> löschen Sie den Inhalt der Zelle.

## Jetzt Sie!

Schreiben Sie in die Zellen **A1** bis **A5** fünf Obstsorten untereinander. Drücken Sie nach jeder Sorte <kbd>↵ Enter</kbd>.

## Hat nicht geklappt?

- **Der Text ist breiter als die Zelle:** Das ist kein Fehler. Wie Sie die Spalte breiter machen, lesen Sie in der Anleitung [„Wie mache ich meine Tabelle übersichtlich?“](../uebersichtlich/).
- **Ich habe aus Versehen etwas gelöscht:** Drücken Sie <kbd>Strg</kbd> + <kbd>Z</kbd>.
