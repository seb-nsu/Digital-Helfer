## So drucken Sie

1. Öffnen Sie das Dokument, zum Beispiel einen Brief in Word, eine E-Mail oder eine Internetseite.
2. Drücken Sie gleichzeitig <kbd>Strg</kbd> + <kbd>P</kbd>. Das **P** steht für „Print“, englisch für Drucken.
3. Ein Fenster zum Drucken öffnet sich. Oben steht der Name Ihres Druckers. Daneben oder rechts sehen Sie eine Vorschau.
4. Bei **Kopien** stellen Sie ein, wie oft gedruckt werden soll. Meist bleibt hier eine **1** stehen.
5. Klicken Sie auf **Drucken**. Der Drucker legt los.

## Nur bestimmte Seiten drucken

1. Suchen Sie im Druckfenster das Feld **Seiten**.
2. Wählen Sie statt **Alle** zum Beispiel **Benutzerdefiniert** und tippen Sie die Seitenzahl ein, etwa **1** oder **2-3**.

> **Gut zu wissen:** Mit <kbd>Strg</kbd> + <kbd>P</kbd> drucken Sie in Word, Excel, im Browser und in Outlook. Steht oben beim Drucker **Microsoft Print to PDF**? Dann wird nichts gedruckt, sondern eine Datei gespeichert. Wählen Sie dort Ihren richtigen Drucker.

## Jetzt Sie!

Drucken Sie diese Anleitung aus. Drücken Sie dafür jetzt <kbd>Strg</kbd> + <kbd>P</kbd>.

## Hat nicht geklappt?

- **Der Drucker druckt nicht:** Lesen Sie [„Der Drucker druckt nicht“](../../probleme/drucker/).
- **Das Druckfenster ist nicht erschienen:** Klicken Sie einmal in das Dokument und drücken Sie dann noch einmal <kbd>Strg</kbd> + <kbd>P</kbd>.
